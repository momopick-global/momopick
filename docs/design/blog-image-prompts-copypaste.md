# Blog Image Prompts — 복붙용 (재밌는 상황 + 제목 포함)

> 작성 기준일: 2026-07-09
> 이미지가 필요한 블로그 글 14편. 각 코드블록을 통째로 복사해 ChatGPT 등 AI 이미지 도구에 붙여넣으면, **재밌는 상황 일러스트 + 한글 제목 + 작은 영문 제목**이 함께 생성됩니다.
> 상세 규격: [image-guidelines.md](./image-guidelines.md)

## 공통 규칙 (프롬프트에 이미 반영됨)

- 1:1 정사각형, 파스텔 플랫 일러스트, 상황 중심(정적 초상 X)
- 텍스트는 **딱 두 줄** — 한글 제목 + 작은 영문 부제 (많이 넣을수록 깨짐)
- 카테고리 색: 썸·연애=코랄/블러시, 성격·심리=라벤더, 재미·스토리=민트/옐로
- 텍스트는 하단 밴드(soft panel) 위에 배치 → 가독성 + 글자 안정
- 생성 후 한글이 어색하면: 텍스트 빼고 배경만 뽑은 뒤 제목은 따로 얹기

> 저장: `public/images/blog/<파일명>` → `koSamplePosts.ts`의 `image` 값 교체 → `npm run build`
