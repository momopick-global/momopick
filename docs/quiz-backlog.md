## 제작 체크리스트 (모든 퀴즈 공통)

1. 오답 보기에 개그 1~2개 (정답 1 + 그럴듯한 오답 1 + 뻔뻔한 개그 1~2 구성)
2. 해설/결과 문구 = "웃긴 한 줄 + 실제 정보" 구조
3. 제목은 밈형 훅 (자기부정형 오프닝, `-력`/`-지수`/`-검정` 계열), "능력고사" 금지
4. `related` 3개 채우기 (시리즈 연쇄 이동), 스낵이면 `compat`(best/worst)도
5. ko/en 전체 번역, 썸네일 ko/en (OMR·그라데이션 스타일 유지)
6. 등급/구간은 0~100 빈틈없이, 칭호는 밈형 (스낵이면 결과 4~8종)
7. 등록: JSON → `index.ts` (named export + 카탈로그 + koQuizCatalogForHome) → 페이지 라우트 → `node tools/check-quiz-images.mjs`

## 성과 기준 (퍼널 지표로 판정)

- 완료율(`__complete`÷start) 70% 미만 → 문항 수·난이도 점검
- 공유율(`__share`÷complete) 상위 퀴즈의 포맷을 다음 제작에 반영
- `__fb_miss`가 fit보다 많으면 결과 카피 리라이팅
