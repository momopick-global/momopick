# 퀴즈 제목과 결과 정리

기준: `src/content/quiz/*.json`

| 슬러그 | 제목 | 결과 |
|---|---|---|
| `ambiguous-situationship-end` | 썸이 항상 애매하게 끝나는 이유 | 밀당형 / 직진형 / 눈치형 / 과해석형 |
| `anger-style-test` | 화났을 때 나는? | 폭발형 / 직진형 / 회피형 |
| `dating-expert-or-beginner` | 나는 연애 고수일까 연애 초보일까? | 90%↑ 고수 / 70% 매력형 / 50% 애매형 |
| `emotional-sensitivity` | 나는 왜 예민할까? | 공감형 / 균형형 / 과해석형 |
| `hidden-dark-side` | 나의 숨겨진 다크사이드 | 통제형 / 폭발형 / 냉소형 |
| `leader-or-supporter` | 나는 리더형인가 조력자형인가? | 리더 / 전략가 / 서포터 |
| `love-pattern-destroying-habit` | 내가 연애를 망치는 한 가지 습관 | 과몰입형 / 무관심형 / 회피형 / 집착형 |
| `mental-strength-test` | 나는 멘탈 강자일까 유리멘탈일까? | 강철 멘탈 / 탄성형 멘탈 / 유리 멘탈 |
| `personality-psychology-test` | 나의 성격·심리 분석은? | 분석형 / 공감형 / 균형형 / 직관형 |
| `true-self-alone` | 나는 혼자 있을 때 어떤 사람? | 사색형 / 소비형 / 방전형 |
| `trust-level-test` | 나는 사람을 잘 믿는 편일까? | 경계형 / 신뢰형 / 맹신형 |
| `when-men-lose-interest` | 남자가 나에게 식는 순간 | 무심형 / 부담형 / 과속형 |
| `who-likes-you-type` | 나를 좋아하는 사람은 어떤 타입? | 안정형 / 집착형 / 친구형 / 장난형 |
| `why-cant-you-text-first` | 나는 왜 먼저 연락을 못할까? | 상처회피형 / 자존심형 / 계산형 |

## 퍼센트·지표형 퀴즈

| 슬러그 | 제목 | 결과 |
|---|---|---|
| `confession-success-rate` | 나의 고백 성공 확률은? | 지금은 타이밍이 아님 / 가능성은 있지만 애매 / 지금 고백해도 좋다 |
| `logical-or-emotional` | 나는 이성적일까 감성적일까? | 감성 80% / 균형형 / 이성 75% |
| `love-temperature-test` | 나는 어떤 연애 온도일까? | 차가운 연애 (20°) / 균형 잡힌 연애 (50°) / 뜨거운 연애 (90°) |
| `planner-or-spontaneous` | 나는 계획형인가 즉흥형인가? | 즉흥 70% 이상 / 균형형 / 계획 80% 이상 |
| `relationship-balance-test` | 연애 중 나는 갑 vs 을? | 을 80% / 균형 / 갑 70% |
| `self-esteem-level` | 나의 자존감 레벨은? | 자존감 낮음 / 자존감 보통 / 자존감 높음 |

## 참고

- `confession-success-rate`, `relationship-balance-test`는 결과를 점수 구간으로 표시합니다.
- `logical-or-emotional`는 이성 / 감성 2축 결과를 함께 보여줍니다.
- `love-temperature-test`는 온도형 결과, `planner-or-spontaneous`와 `self-esteem-level`은 퍼센트형 결과입니다.
