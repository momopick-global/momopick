# 결과 이미지 생성 프롬프트 — 스낵 신작 5종 (26장)

> 기존 결과 카드(who-likes-you-type 등)와 동일한 아트 디렉션. 생성 도구: 한글 텍스트 렌더링이 되는 이미지 모델 권장.

## 공통 스타일 블록 (모든 프롬프트 앞에 붙여서 사용)

```
정사각형(1:1, 1024×1024) 모바일 심리테스트 결과 카드 일러스트.
고품질 애니메 일러스트 스타일, 화려한 장식 프레임(이중 테두리)이 카드 전체를 감싼다.
레이아웃(위→아래):
1) 상단: 결과명을 크고 두꺼운 입체(3D) 한글 타이포로 — 광택과 외곽선, 주변에 작은 장식 이펙트
2) 그 바로 아래: 알약형 리본 배너 안에 태그라인 텍스트
3) 중앙(카드의 60%): 캐릭터 일러스트 장면
4) 하단: 리본 배너 안에 한 줄 카피(핵심 단어만 노랑 강조)
질감: 반짝이는 하이라이트, 부드러운 그라데이션 배경, 아기자기한 소품.
텍스트는 반드시 지정된 한국어 문구를 정확히 렌더링할 것(오타 금지).
```

**사용법**: 위 블록 + 아래 각 결과의 프롬프트를 이어붙여 생성 → `public/images/quiz/{slug}/ko/result-{n}.webp`로 저장(1024×1024, webp).
영문판이 필요하면 같은 프롬프트에서 텍스트만 en 문구로 교체해 `/en/`에 저장.
이미지가 준비되면 JSON의 `results[key].image`에 `/images/quiz/{slug}/result-{n}.webp` 경로를 넣으면 됩니다(로케일 세그먼트 없이 — 요청 시 제가 일괄 반영).
